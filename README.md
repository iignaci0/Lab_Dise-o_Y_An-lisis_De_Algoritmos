# Laboratorio: Optimización del TSP mediante Ramificación y Poda

Repositorio correspondiente al desarrollo empírico del Problema del Viajante de Comercio (TSP) utilizando el algoritmo de *Branch and Bound*. Este proyecto incluye el motor de instrumentación y los datos crudos para evaluar distintas estrategias de exploración y funciones de acotación.

## 🚀 Requisitos y Ejecución
El código está desarrollado en Python puro utilizando únicamente librerías de la biblioteca estándar (`math`, `copy`, `heapq`, `json`). No requiere instalación de dependencias externas.

Para ejecutar los 4 escenarios de prueba y regenerar la telemetría, simplemente ejecute:
```bash
python main.py
